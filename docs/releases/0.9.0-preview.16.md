# wake-bridge 0.9.0-preview.16

This preview makes out-of-process Host Adapter file errors name the field that is wrong, and lets `doctor` report those mistakes before the daemon environment is loaded. Core behavior is unchanged from 0.9.0-preview.15.

## Host Adapter file errors

- A `host-adapters.json` without `receipt_upper_bound` failed with `out-of-process host receipt upper bound is unsupported`, which read as the feature being unsupported, and removing the field gave the same message. It now says `receipt_upper_bound is required; use accepted_to_live_pipe or host_accepted`, and `agent_completed` is rejected as unavailable to out-of-process hosts.
- The other file errors also name the field and what it accepts: `id`, `token_env`, `adapter_kind`, `adapter_version`, `host_kind`, `tested_host_versions` and `attention_channels`.
- Bootstrap token environment variables are checked only after the whole file is valid. Running `doctor --host-adapters` in a shell that has not loaded `daemon.env` now reports file mistakes first, and the missing token only once the file is valid.
- The accepted values have not changed. `receipt_upper_bound` and `tested_host_versions` were already required.

## Documentation

- Linux runbook: run `doctor` with the same Host Adapter and source credential files before `service install`. `release-preflight` does not read these files. A daemon that fails to load them exits before it listens, so systemd keeps restarting it, and the reason is in `journalctl`.
- The out-of-process Host Adapter guide states that `tested_host_versions` is required.
- `wakebridge help` lists the `doctor` options.

## Verification

- Core/package suite: 143 tests passed.
- Claude CLI Host Adapter suite: 17 tests passed.
- New tests check each Host Adapter file error message, that a file mistake in a later adapter is reported before a missing token for an earlier one, and that `doctor` without the token environment reports the file mistake.

## Upgrade notes

- No schema migration is required, and Core behavior is the same as 0.9.0-preview.15.
- A Host Adapter file that loads on 0.9.0-preview.15 loads unchanged. If a file fails to load, the error now names the field to fix.
