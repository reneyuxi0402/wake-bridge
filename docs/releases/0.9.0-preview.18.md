# wake-bridge 0.9.0-preview.18

本版集中修复真实接入中的投递可靠性、安装与排障体验，不扩展通用宿主支持承诺。

## 投递与诊断

- 修复并发 Claim 合并时可能丢失引用的问题。派发前重新检查过期、presence、quiet hours 与 endpoint lease，避免使用过时的调度条件。
- 已有 Claim 全部完成的待派发批次可以安全收尾，保留 attempts、receipts 和原引用；缺失引用不冒充完成证据，已接受或正在投递的批次不被撤回。
- 明确区分 transport accepted、host attested 与 agent seen。HTTP 回程丢失不抹掉已验证的真实宿主注入证据，也不补造接受回执。
- 增强只读 `attention_wake_health`，提供批次证据、Core 自动派发候选资格、待确认/逾期状态和下一步检查提示；不替 agent ack、consume 或盲目重投。
- 未被接受且可重试的 transport failure，在没有有效 `retry_after_ms` 时采用有上限的指数退避：默认 5、10、20、40、80、160、300 秒，此后每次 300 秒。复用持久化累计 attempt，重启或换 generation 不归零；有效的 `retry_after_ms` 仍优先。这不是尝试次数上限，也不保证 exactly-once。

## 安装与使用

- CLI 严格检查参数，help 不要求先打开数据库，doctor 的失败会返回非零退出码；补齐列表查询参数与配置校验。
- quiet-hours 实例配置真正传入 Core；策略预览显示保留的已安装规则，不把默认配方误报为当前生效配置。
- macOS service 保留 host/source 配置路径与可选环境文件；Linux systemd EnvironmentFile 修复空格、Unicode 与特殊字符路径处理。SQLite CLI 的最低要求明确为 3.35.0，另须支持 JSON 输出与 JSON1。
- Gmail 轮询新增共享请求时限与候选检查上限，保留已取得的进度，避免长轮询反复撞上 connector 超时。
- 文档明确实验性 Claude CLI adapter 与仅打印 envelope 的 reference adapter 的区别，以及 host 接受时限、ack 竞争、batch 合并策略和 watch 的活动基线。Watch enabled 不等于 armed，绑定 endpoint 本身不会启动静默倒计时。

## 验证范围

发布前本地回归覆盖 389 项 Vitest 测试与 17 项 Claude adapter Node 测试，包含仓库外 tarball 安装黑盒验证。
Linux lifecycle 修复在 Ubuntu 22.04 x64 / systemd 249 上完成安装、特殊环境文件路径、备份、同前缀升级、服务重启和回滚验证。
本轮另有 Claude CLI 2.1.278 的 idle/restart 与独立测试账号新通知的真实 ack → 权威来源读取 → consume 证据。

这些现场结果不代表任意 busy session 都能及时处理：busy 测试曾出现 host 已注入但 agent 未确认，后续仅在明确兼容任务条件下恢复。
新通知验证也不等于长期轮询稳定性测试。Claude idle/restart/busy 的具体范围和失败记录见 [Claude adapter verification](../../host-adapters/claude-cli/docs/verification.md)。

## 升级与兼容性

显式安装：`npm install --global wake-bridge@0.9.0-preview.18`。
升级前按 [release lifecycle](../operations/release-lifecycle.md) 备份并核对运行中的 package/config/service 路径；本次发布不自动升级或重启任何现有实例。

- DB schema 仍为 8，没有新增迁移；已有策略和来源启用状态不自动覆盖。
- 旧脚本中曾被忽略的未知或重复 CLI 参数现在会明确报错，请先修正参数再运行。
- 已保存的 retry `not_before` 不重写，后续失败才采用新的退避规则。直接嵌入 Core 的既有 `retry_delay_ms` 保留为基数，0 仍立即重试，大于 300 秒的基数不会被缩短；没有新增 CLI/实例配置项。
- 接受投递不等于 agent 已读或来源已处理。缺 agent ack 的已接受批次不因本版退避机制自动重投。
- 延续 preview.17 的小机知道摘要检测及 from-now 基线要求；从更早版本升级时仍须阅读 [preview.17 升级说明](0.9.0-preview.17.md)。
