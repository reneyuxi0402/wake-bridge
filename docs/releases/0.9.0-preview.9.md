# wake-bridge 0.9.0-preview.9

发布日期：2026-09-12。状态：npm `preview` + GitHub pre-release。macOS/Ubuntu CI 已通过；腾讯云 Ubuntu 22.04 LTS x64
实机已完成连续两轮 reboot canary。

## 目标

在不改变 Event/Claim/Batch、SQLite schema 或 loopback Host Adapter Contract 的前提下，为 Wake Bridge 增加首个诚实的
Linux VPS release profile。

## 变更

- npm manifest 与 release preflight 允许 `linux`；
- `wakebridge service install/uninstall` 按平台选择 macOS LaunchAgent 或 Linux systemd user service；
- Linux unit 固定 `127.0.0.1`、`UMask=0077`、`Restart=on-failure` 与 journald 输出；
- unit 可引用 Host Adapter/Source Connector manifest、mode-600 daemon environment file 与 source credential file，
  但不复制 token 到 unit 或 argv；
- 增加 Ubuntu 24.04 LTS x64 / Node 20 GitHub Actions job、Linux unit 测试、clean-tarball 平台分支与 VPS runbook；
- npm 正式测试入口固定在 public `test/`，仓库内 Node TAP integration 不再被 Vitest 误收集。

## 支持口径

Linux profile 覆盖 Core、Source Connector、Host Adapter 与 agent runtime 全部同机、使用 systemd user service 的 x64 VPS。
真实 VPS 证据来自 Ubuntu 22.04 LTS / systemd 249，Ubuntu 24.04 x64 当前只有 CI 证据。所有 Wake Bridge transport 保持
loopback。Bridge 在 VPS、runtime 在另一台机器的 Remote Host Adapter 不在本版本内。

`os: linux` 只让 package 可以安装，不代表所有 distro、Linux arm64、容器、WSL、NAS 或无 systemd 环境都已验证。
arm64 必须有独立真实 runner/canary 后才可加入已验证矩阵。

## 当前证据

- macOS typecheck/build：通过；
- public Vitest：22 个 test files / 106 项测试通过；
- clean-tarball import/init/daemon/emit/inspect/Host Adapter/backup/upgrade/restore/macOS service profile：通过；
- Linux preflight、systemd unit 生成、特殊字符转义、secret absence、mode-600 gate、重复安装与数据保留卸载：在 macOS
  上通过平台注入测试；
- 22 个公开 Markdown 文件相对链接检查：通过。
- GitHub Actions [CI run 34623272836](https://github.com/reneyuxi0402/wake-bridge/actions/runs/34623272836)：
  Ubuntu 24.04 与 macOS 上的 Node 20/24 四个 job 全部通过。
- 既有腾讯云 Ubuntu 22.04 LTS x64 / systemd 249 VPS 已完成 clean tarball、独立非 root 用户、linger、systemd
  lifecycle、reference Host Adapter、在线备份，以及连续两轮整机 reboot 后的自动恢复与 synthetic receipt；
- 实机 UAT 发现旧版 systemd 不接受带双引号的 `EnvironmentFile=` 路径。本版本已改为不带引号的 UTF-8 字节转义路径，
  并增加含空格、`$`、`%` 的回归测试；reference adapter demo sink 也不再向 journal 输出 delivery nonce。
- 并行 operator 检查暴露出当前 schema 数据库仍会重放 schema 写入、使另一个进程短暂读到中间版本的问题。current schema
  现在以无 schema 写入方式打开；新增数据库字节保持不变的回归测试，只有新库或显式授权的旧库升级会执行 schema 写入。读取
  `PRAGMA user_version` 也使用 SQLite busy timeout；真实 VPS 上两路 operator 命令并发十轮全部通过。

## 已知验证空白

- 尚未在独立 Ubuntu 24.04 LTS x64 VPS 复现 Ubuntu 22.04 canary；
- package rollback 与 service profile rollback 尚未实操；
- 尚未验证 Claude Code、Codex Desktop 或其他具体 agent runtime；本版本只承诺公开 Host Adapter Contract；
- Linux arm64、容器、WSL、NAS 与无 systemd 环境不在已验证矩阵。
