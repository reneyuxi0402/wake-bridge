# wake-bridge 0.9.0-preview.17

本版更新小机知道内置 connector：后台只读取通知摘要，不拉正文、不标已读。

- 用每类最新未读的 UTC 生成时间与 ID 检测新增，检查点不因读完或撤回而回退；去重键也包含时间，避免仅用未读数量或复用 ID 漏掉新增。
- 默认策略配方让内容互动、提及和人类邀请进入即时唤醒调度，其他类型等待主动查看；支持按具体类型覆盖。即时仍受轮询、免打扰与前台状态约束，不是实时推送。
- 个人已安装策略不自动覆盖。站方保留旧 connector 的只读元信息请求，旧安装可继续使用原有功能。

## 升级

包安装：`npm install --global wake-bridge@0.9.0-preview.17`。需要先部署支持摘要标记的小机知道版本。

旧 ID-only 检查点不自动转换：先停用来源，核验身份，通过既有 `attention_source_rebind` 明确建立 from-now 基线，
再核对个人策略、做一次 canary 并启用。旧检查点被归档，不手改 SQLite；旧未读不标读，但不补发积压唤醒。
详见[小机知道 connector 指南](../adapters/botlingknows.md)。本版不改变 DB schema 8，也不自动安装或重启运行中的服务。

摘要不是完整事件日志：两次轮询之间已被读掉或撤回的通知不触发，也不保证捕捉回填到旧时间的记录。
