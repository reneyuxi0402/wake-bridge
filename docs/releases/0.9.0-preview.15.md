# wake-bridge 0.9.0-preview.15

This preview adds a SQLite JSON1 check to `release-preflight`, moves releases to the npm `latest` dist-tag and brings the documentation up to date. Core behavior is unchanged from 0.9.0-preview.14.

## release-preflight

- Since 0.9.0-preview.14, Core reads claim and batch id arrays with SQLite's JSON1 functions (`json_each`, `json_array_length`). `release-preflight` only checked `-json` output, so a SQLite CLI built without JSON1 (possible before 3.38) passed preflight and then failed every scheduler pass.
- Preflight now reports `runtime.sqlite3.json_functions` and requires it for `supported` and `ok`.

## Distribution

- Releases publish to the npm `latest` dist-tag. The `preview` dist-tag has been removed, so `wake-bridge@preview` no longer resolves; install with `npm install --global wake-bridge`.
- The README shipped inside 0.9.0-preview.14 still shows the old `@preview` command; this release's README is correct.

## Documentation

- Protocol: list windows for `event.list` / `claim.list`, acknowledgement-timeout reconciliation in the batch state machine, claim retention and `claim_pruned`, and transaction atomicity.
- Architecture and the out-of-process Host Adapter guide describe retention and acknowledgement-timeout reconciliation.
- README lists the operator features and the Gmail connector, and links the operator control and Gmail guides.
- Every SQLite requirement now names JSON1.
- The Linux runbook states that its real-VPS reboot evidence comes from 0.9.0-preview.9; service and release lifecycle have not changed since.
- The maintainer release checklist now includes updating the documents that name the current version.

## Verification

- Core/package suite: 142 tests passed.
- Claude CLI Host Adapter suite: 17 tests passed.
- A CLI test runs `release-preflight` against a SQLite stand-in that supports `-json` output but not JSON1, and expects `json_functions: false` and exit code 2.

## Upgrade notes

- No schema migration is required, and Core behavior is the same as 0.9.0-preview.14.
- If `wakebridge release-preflight` reports `json_functions: false`, install a SQLite CLI with JSON1 before running 0.9.0-preview.14 or later.
