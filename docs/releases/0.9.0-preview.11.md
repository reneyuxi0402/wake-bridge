# wake-bridge 0.9.0-preview.11

This preview bundles the official experimental Claude CLI online-session Host Adapter in the `wake-bridge` package.

## Added

- `wakebridge-claude launch` starts an explicitly owned Claude Code TTY session with a scoped custom channel, lifecycle hooks, endpoint registration, lease renewal, generation fencing, and explicit Wake Bridge acknowledgement tooling.
- The adapter and its verification record now live in the Wake Bridge repository under `host-adapters/claude-cli/` and ship in the main npm artifact.

## Verified boundary

- Verified against Claude Code 2.1.270 for idle wake, busy queue delivery, model-generated acknowledgement, exit lease closure, and detached tmux operation.
- `-p` / `--print`, non-TTY `stream-json` sessions, Claude Desktop, cold launch, and retroactive attachment remain unsupported.
- Delivery evidence remains capped at `accepted_to_live_pipe`; it does not claim the model read or acted on a wake.

## Packaging correction

The Claude CLI adapter follows the Wake Bridge release version and is installed with `wake-bridge@preview`. The separately published `wake-bridge-claude-cli@0.1.0-preview.1` package is superseded and should not be used for new installations.
