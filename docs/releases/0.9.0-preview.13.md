# wake-bridge 0.9.0-preview.13

This preview bundles the first available Gmail Source Connector in the main `wake-bridge` package. It remains optional and disabled by default.

## Gmail Source Connector

- `wakebridge gmail-connector` runs a loopback-only connector process and keeps Google OAuth credentials outside the Wake Bridge daemon.
- `users.getProfile` binds the manifest to the authenticated account; owners must still verify identity and perform an explicit from-now bootstrap before enabling a source.
- Gmail History API pagination keeps the durable history waterline, opaque `nextPageToken`, and page-local message offset separate so bounded polling cannot skip an expanded page.
- Expired history cursors fail closed as `gmail_history_expired` and enter `needs_attention`; the connector never silently re-anchors past an unknown gap.
- Message lookup uses `format=metadata` with partial fields. Durable events contain only message/thread references and a `gmail://message/<id>` authoritative resource, never Subject, From, snippet, body, attachments, or headers.
- OAuth files must be regular mode-600 files. The manifest reports the credential's actual scopes and marks credentials with modify/settings/send authority as `broad` even though the connector exposes only metadata reads.

## Catalog and packaging

- Gmail is `available`, bundled, enableable, and still `disabled` by default.
- Every Agent Space must complete configure → verify identity → from-now bootstrap → canary UAT → explicit enable.
- The connector implementation, CLI entry point, env template, operator documentation, and tests ship in `wake-bridge`; no separate Gmail npm package is required.

## Verification

- The resulting minimal event passed an isolated event → claim → wake → acknowledgement → consume flow without touching a production Wake Bridge database or service.
- Core/package suite: 123 tests passed.
- Claude CLI Host Adapter suite: 17 tests passed.

## Upgrade notes

- No schema migration is required for this preview.
- Publishing or installing the package does not configure Gmail, copy OAuth credentials, enable the connector, or restart an existing Wake Bridge service.
