# wake-bridge 0.9.0-preview.22

本版为 Agent MCP 增加有界批量操作，减少大量陈旧 claim 或多个 source 需要逐条处理时的工具往返与 token 消耗。发行仍以同 tag 四组门禁和实际可下载产物为准。

## 批量 Agent MCP

- `attention_dismiss_many` 与 `attention_consume_many` 单次接受 1–500 个不重复 claim ID；沿用单项操作的状态机、receipt 与错误语义。
- `attention_source_enable_many` 与 `attention_source_disable_many` 单次接受 1–100 个不重复 source ID；每个 enable 仍独立核验 live connector identity 与 durable checkpoint。
- 四个接口都返回 `requested`、`succeeded`、`failed` 和按输入顺序排列的紧凑逐项结果。单项失败不回滚已成功条目，也不迫使调用者重发整批。
- 原有单项接口保持不变。当前批量接口只接受显式 ID 列表，不提供按筛选条件直接大面积写入的隐式操作。

## 验证与支持边界

2026-11-16（America/Los_Angeles）本地 macOS arm64 / Node 20.20.1：typecheck 通过；46 个 Vitest 文件共 604 项与 Host Adapter 17 项全部通过；发布 tarball 仍由同 tag workflow 在 macOS / Ubuntu 24.04 × Node 20 / 24 上复验后才上传 npm 与 GitHub pre-release。

本版不改变 SQLite schema、Host Adapter Contract、Source Connector contract 或 owner HTTP/CLI 表面；运行中旧 MCP 进程需重启或随宿主会话重建后才会列出新工具。
